 🔐 Caesar Cipher Encryption & Decryption Tool

A simple Python-based Caesar Cipher tool that allows users to encrypt and decrypt messages using a shift key.

>>Features

- Encrypt plain text
- Decrypt encrypted text
- Supports uppercase and lowercase letters
- Preserves spaces and special characters
- Easy-to-use command line interface

>> Technologies Used

- Python 3

>>How It Works

The Caesar Cipher is one of the oldest encryption techniques. It shifts each letter in a message by a fixed number of positions in the alphabet.
step 1 : CMD 
step 2 : py "Basic Caesar Cipher Encryption & Decryption Tool.py"
step 3 : enter e 
step 4 : enter any word
Example:

Plain Text: hope
Shift: 1
Cipher Text: ipqf
